# Brainstorming Skill

When a requirement is broad, novel, or offers multiple design paths:
1. **Identify the Core Goal**: State what problem is actually being solved.
2. **Present 2–3 Viable Approaches**:
   - Option A: Minimalist / lowest friction
   - Option B: Full-featured / extensible
   - Option C: Pragmatic alternative
3. **Contrast Trade-Offs**: Compare complexity, maintenance cost, speed, and dependencies.
4. **Recommend the Strongest Option**: Clearly state the recommended approach with justification and ask for user confirmation.
