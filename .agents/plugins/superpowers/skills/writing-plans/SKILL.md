# Writing Plans Skill

For any multi-step task or refactor:
1. **Context & Objective**: Briefly summarize what will be achieved and why.
2. **Current State Analysis**: Reference existing files, functions, and call sites.
3. **Step-by-Step Execution Sequence**:
   - Step 1: Specific file changes and reason.
   - Step 2: Dependent updates and imports.
   - Step 3: Verification steps (commands, manual checks).
4. **Safety & Fallback**: Identify potential regression risks and mitigation steps.
