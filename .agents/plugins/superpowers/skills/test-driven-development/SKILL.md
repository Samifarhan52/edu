# Test-Driven Development (TDD) Skill

When implementing new logic, fixing bugs, or modifying endpoints:
1. **RED**: Identify or create a reproduction/test case that reliably fails on the bug or missing feature.
2. **GREEN**: Write the minimal code required to satisfy the condition and turn the check green.
3. **REFACTOR**: Clean up any duplication, remove temporary debug statements, and ensure compliance with coding standards without breaking the passing test.
4. **VERIFY**: Run complete regression checks across all related components.
